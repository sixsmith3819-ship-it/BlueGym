## 🔑 GitHub Login

When Git asks for credentials:

**Username:** Your GitHub username

**Password:** Use Personal Access Token (NOT your GitHub password)

### How to Get Token:
1. Go to: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Give it a name: "Blue Gym Push"
4. Select scope: ✅ `repo` (full control)
5. Click "Generate token"
6. **COPY THE TOKEN** (you won't see it again!)
7. Use as password when Git asks

## 🐛 Troubleshooting

### "Git not found"
**Solution:** Install Git from https://git-scm.com/download/win

### "Repository not found"
**Solution:** 
- Make sure repo exists: https://github.com/Guruzzz/Blue-Gym
- Check you're logged into correct GitHub account

### "Authentication failed"
**Solution:** 
- Use Personal Access Token, NOT password
- Generate at: https://github.com/settings/tokens
- Select `repo` scope

### "Failed to push"
**Solution:**
```cmd
git pull origin main --rebase
git push -u origin main
```

### "Remote already exists"
**Solution:**
```cmd
git remote remove origin
git remote add origin https://github.com/Guruzzz/Blue-Gym.git
```
