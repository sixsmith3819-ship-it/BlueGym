## 🆘 If Something Goes Wrong

### install.bat failed?
Run this in Command Prompt:
```cmd
cd C:\Users\terre\Desktop\Blue Gym\blue-gym
npm install --legacy-peer-deps
```

### dev.bat not starting?
Make sure `npm install` completed successfully first.

### Port 3000 in use?
Run dev on a different port:
```cmd
npm run dev -- -p 3001
```
